# PERSONAS.md — persona definitions

A persona = your twin's identity + voice + face + a signature glow. Demo
personas below are seeded; every real user creates their own from a bio.

## Rules
- The same prompt must produce visibly (glow, stage, caption styling) and
  audibly (voice/tone/pacing) different output per persona — that's the
  1:10–2:10 wow: switch persona mid-flow, same task, different twin.
- Switching persona: orb morph + glow crossfade + voice change in <400ms
  (CSS transitions on transform/opacity only, no layout shift).
- Glow is state, not decoration: idle = breathing, listening = mic-reactive
  pulse, thinking = orbiting shimmer, speaking = audio pulse.
- Each persona's facts/hypotheses stay separate; glow never implies truth.
