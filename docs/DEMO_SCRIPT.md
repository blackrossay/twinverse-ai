# Demo script (2:45) + recording guide

Record on macOS with Cmd+Shift+5 (screen area → record), 1080p min, mic on.
Do a full dry run first; keep this backup recording even if demoing live.

## 0:00–0:25 — Create the twin

1. Open http://localhost:3000. Point out the **live** badge (real Meta model).
2. Click **Seed demo personas** (or New twin → paste a 3-sentence bio → Create).
3. Open **Alex Morgan**: facts vs dashed "inferred, not verified" hypotheses,
   version selector, provenance list. One line: "facts and guesses are never mixed."

## 0:25–0:55 — Spawn three realities

1. **New simulation** → Alex Morgan → all three scenarios → Launch.
2. Narrate while it runs (~40s, all parallel): "one frozen identity snapshot,
   three isolated contexts — negotiation, escalation, leadership crisis."
3. Scroll the three independent progress states.

## 0:55–1:40 — Compare outcomes

1. When done, scroll to **Comparison**: read the one-paragraph summary aloud.
2. Open the three score cards: consistency/effectiveness/adaptation with notes,
   plus deterministic code checks (grounded fact ids, variables acknowledged).
3. One line: "scores are model estimates with evidence; checks are code."

## 1:40–2:15 — Change a variable

1. Scroll to **Rerun with changes**: set negotiation `time_pressure` to
   "extreme — 4 hours", rerun that scenario only.
2. On the child run, show the parent link ("parent preserved unchanged") and
   the **What changed** diff: variable delta, before/after responses, score deltas.

## 2:15–2:45 — Reveal the vision

"Same identity core, same engine — swap the templates and rubrics and this
becomes interview coaching, support training, or classroom roleplay. One
identity. Multiple realities. Measurable outcomes."

## If something fails live

Say so, show the error state (they're honest by design), then cut to the
backup recording. Never present fixtures as live output — the UI labels them.
